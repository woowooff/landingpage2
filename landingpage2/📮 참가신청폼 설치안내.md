# 📮 제주다회 참가신청폼 설치안내

> 걸리는 시간: **약 10분**
> 결과: 신청이 들어오면 ① 구글 시트에 저장 ② 내 메일로 알림 ③ 신청자에게 자동회신 — 세 가지가 자동으로 됩니다.
> 내 컴퓨터를 꺼도 24시간 동작하고, 돈은 들지 않습니다.

## ⚠️ 시작 전에 — 계정 확인 (제일 중요)

**반드시 `woogs4444@gmail.com`(개인 계정)으로 로그인한 상태에서 하세요.**

- 감귤박 소개페이지는 **회사 계정**(`suchang.marketing@gmail.com`)으로 만들어져 있습니다. 제주다회는 **개인 계정**입니다. 섞이면 나중에 찾기 어려워집니다.
- 크롬 오른쪽 위 **동그란 프로필 사진**을 눌러 지금 로그인된 계정을 확인하세요.
- 계정이 여러 개면 **크롬 시크릿 창**(`Ctrl+Shift+N`)을 열고 개인 계정으로만 로그인해서 진행하는 게 가장 안전합니다.

> 참고: 예전에 감귤박 작업을 하다가 **개인 계정에 잘못 만든 스크립트와 시트가 방치돼 있습니다.** 작업 중에 보이면 헷갈리니 그때 지워주세요. (어디에도 연결돼 있지 않아 지워도 문제없습니다)

## 1단계 · 구글 시트 만들기 (2분)

1. 주소창에 **`sheets.new`** 를 치고 엔터 → 빈 시트가 새로 만들어집니다.
2. 왼쪽 위 **"제목 없는 스프레드시트"**를 눌러 이름을 **`제주다회 참가신청`** 으로 바꿉니다.

> 시트 안에 칸(머리글)을 직접 만들 필요는 **없습니다.** 첫 신청이 들어오는 순간 코드가 알아서 만듭니다.

---

## 2단계 · 스크립트 붙여넣기 (3분)

1. 방금 만든 시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 새 탭이 열리고 `function myFunction() { }` 같은 코드가 조금 보입니다.
3. 그 코드 영역을 클릭한 뒤 **`Ctrl+A`**(전체 선택) → **`Delete`**(삭제) — 완전히 비웁니다.
4. 이 폴더의 **`apps-script\Code.gs`** 파일을 메모장으로 열어 **`Ctrl+A` → `Ctrl+C`** 로 전체 복사합니다.
5. 비워둔 코드 영역에 **`Ctrl+V`** 로 붙여넣고 **`Ctrl+S`** 로 저장합니다.
6. 왼쪽 위 **"제목 없는 프로젝트"**를 눌러 이름을 **`제주다회 신청접수`** 로 바꿉니다.

---

## 3단계 · 잘 되는지 먼저 시험 (2분)

배포하기 전에 여기서 한 번 확인하면 실수를 줄일 수 있습니다.

1. 화면 위쪽 함수 선택 칸(기본값 `doPost`)을 눌러 **`테스트_신청보내기`** 를 고릅니다.
2. **▷ 실행** 버튼을 누릅니다.
3. 처음이라면 **권한 요청 창**이 뜹니다. 이건 정상입니다.
   - **권한 검토** → 계정 선택(**개인 계정 맞는지 확인!**)
   - "Google에서 확인하지 않은 앱입니다" 경고가 나오면
     → 왼쪽 아래 **고급** → 맨 아래 **'제주다회 신청접수'(안전하지 않음)으로 이동** → **허용**
   - ⚠️ 이 경고는 "내가 방금 만든 내 스크립트"라서 뜨는 것입니다. 문제없습니다.
4. 실행이 끝나면 확인할 것 **두 가지**:
   - 시트로 돌아가면 **`참가신청` 탭**이 새로 생기고 홍길동 한 줄이 들어와 있어야 합니다.
   - `woogs4444@gmail.com` 메일함에 **알림 메일 1통 + 자동회신 1통**, 총 2통이 와 있어야 합니다.

> 여기까지 안 되면 다음 단계로 넘어가지 마세요. 클로드에게 **화면 사진**을 보내주시면 됩니다.

## 4단계 · 웹앱으로 배포하고 주소 받기 (3분)

1. 오른쪽 위 파란 **배포 → 새 배포** 를 누릅니다.
2. 왼쪽 **톱니바퀴(⚙️) → 웹 앱** 을 고릅니다.
3. 아래처럼 맞춥니다. **이 두 칸이 핵심입니다.**

   | 항목 | 골라야 하는 값 |
   |---|---|
   | 설명 | 아무거나 (예: `1차`) |
   | 다음 사용자로 실행 | **나** (`woogs4444@gmail.com`) |
   | 액세스 권한이 있는 사용자 | **모든 사용자** ← ⚠️ 꼭 이걸로 |

   > "모든 사용자"로 안 하면 **신청자가 폼을 눌러도 접수가 안 됩니다.**

4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/...../exec`)을 **복사**합니다.
5. 이 주소를 클로드에게 붙여넣어 주시면 페이지에 연결해 드립니다.
   - 직접 하시려면: 이 폴더의 **`app.js`** 를 메모장으로 열고 **9번째 줄**
     `const GAS_URL = 'PUT_YOUR_WEB_APP_URL_HERE';`
     의 작은따옴표 안을 복사한 주소로 바꾼 뒤 저장하면 됩니다.

## 5단계 · 실제 폼으로 마지막 확인 (1분)

1. `index.html`을 브라우저에서 열고 **`Ctrl+Shift+R`**(강력 새로고침)을 누릅니다.
2. 본인 이름·이메일로 신청을 1건 넣어봅니다. **동의 체크박스도 체크**해야 합니다.
3. "참가 신청이 접수되었습니다"가 뜨고, 시트에 줄이 늘고, 메일 2통이 오면 **끝입니다.**

## 🔧 나중에 코드를 고쳤을 때 (꼭 기억하세요)

`Code.gs` 파일만 고치면 **구글 서버에는 반영되지 않습니다.** 반드시 아래를 같이 해야 합니다.

1. Apps Script 편집기에 새 코드를 **붙여넣기**(`Ctrl+A` → `Delete` → 붙여넣기 → `Ctrl+S`)
2. **배포 → 배포 관리 → 연필(✏️) → 버전: 새 버전 → 배포**

> ⚠️ **반드시 "배포 관리 → 연필"로 하세요.** "새 배포"로 하면 **주소가 바뀌어서** `app.js`도 다시 고쳐야 합니다.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 폼을 눌러도 "전송에 실패했습니다" | 4단계에서 **액세스 권한**이 "모든 사용자"가 아닐 가능성이 큽니다. 배포 관리 → 연필에서 확인 |
| 시트에는 저장되는데 메일이 안 옴 | 구글 무료 계정은 **하루 메일 100통 제한**이 있습니다. 테스트를 많이 했다면 하루 기다리면 풀립니다 |
| 시트 칸이 밀려서 들어감 | 예전 양식으로 만들어진 `참가신청` 탭이 있으면 **탭을 삭제**하고 다시 신청해보세요 (코드가 새로 만듭니다) |
| 권한 경고가 무섭게 뜸 | 정상입니다. **고급 → ...(안전하지 않음)으로 이동 → 허용** |
