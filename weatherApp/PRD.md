## #1 제품 개요 (Why & Who)

여러 지역 날씨를 확인하려면 보통 앱을 열고 지역을 바꿔가며 여러 번 눌러야 한다.
이 앱은 **자주 보는 도시를 즐겨찾기로 저장**해두고, 칩 하나만 눌러 전환하며
**오늘·24시간·7일·미세먼지를 한 화면에서** 보게 한다. 설치 불필요, 링크로 열리는 웹앱.

## #2 유저 이용 흐름 (How)

1. 접속하면 마지막으로 보던 도시(없으면 제주시)의 날씨가 바로 뜬다
2. 상단 검색창에 도시명을 입력 → 결과 클릭 → 즐겨찾기에 추가되고 화면이 그 도시로 바뀐다
3. 즐겨찾기 칩을 클릭해 도시를 전환한다 (칩의 × 로 삭제)
4. °C / °F 버튼으로 단위를 바꾸고, 아래로 스크롤해 24시간 → 7일 → 미세먼지를 확인한다

## #3 핵심 기능 (What)

1. **도시 변경**
   - 검색창 입력 시 300ms 후 자동 검색(Open-Meteo Geocoding, 한국어), 결과 최대 5개 목록
   - 결과 클릭 → 즐겨찾기 칩 추가 + 즉시 해당 도시 표시 + localStorage 저장
   - 기본 즐겨찾기: 제주시 / 서울 / 부산
2. **오늘 날씨(현재)** — 큰 기온, 날씨 상태(한글), 체감온도, 최고/최저, 강수확률, 습도, 바람, 자외선, 일출·일몰
3. **24시간 시간별** — 현재 시각부터 24개 카드를 **가로로 배치**(가로 스크롤). 각 카드: 시각, 날씨 아이콘, 기온, 강수확률
4. **7일 예보** — 7개 카드를 **가로로 배치**. 각 카드: 요일, 아이콘, 강수확률, 최고/최저 + 기온 막대
5. **미세먼지** — PM2.5 / PM10 수치와 한국 기준 4단계 등급(좋음·보통·나쁨·매우나쁨) 색상 표시
6. **°C / °F 전환** — 재요청 없이 화면에서 즉시 변환, 선택값 저장
7. **날씨 반응형 배경** — 맑음(낮/밤)·흐림·비·눈·안개·뇌우에 따라 배경 그라데이션이 부드럽게 전환
8. **반응형** — 모바일 1단, 태블릿·PC 2단 배치

## #4 Out of Scope (이번에 안 만드는 것)

- 로그인·회원가입, 서버·데이터베이스 (전부 브라우저 localStorage)
- 알림/푸시, 위젯, 네이티브 앱
- 지도, 레이더 영상, 기상 특보
- 광고, 결제

## #5 성공 지표 (KPI)

- 접속 3초 안에 현재 날씨가 보인다 (로딩 스켈레톤 포함)
- 도시 전환이 클릭 1번으로 되고, 새로고침해도 즐겨찾기가 남아 있다
- 모바일(폭 390px)에서 가로 스크롤 없이 모든 정보가 읽힌다
- 화면에 빈 공간이 없이 정보가 채워져 보인다 (사용자 최초 요구사항)
