# 📮 문의폼 설치 안내 (10분이면 끝납니다)

> 이 작업을 하면 랜딩페이지의 "문의 보내기" 버튼이 이렇게 동작합니다.
> ① 구글 시트에 자동 저장 → ② `suchang.marketing@gmail.com` 으로 알림 메일 → ③ 신청자에게 "접수됐습니다" 자동회신
>
> **돈 안 듭니다.** 구글 계정 하나면 되고, 서버도 필요 없습니다.
> **반드시 `suchang.marketing@gmail.com` 계정으로 로그인한 상태에서** 진행하세요.

---

## 1단계 — 문의가 쌓일 구글 시트 만들기

1. 크롬 주소창에 **`sheets.new`** 를 입력하고 엔터 → 빈 구글 시트가 새로 만들어집니다
2. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 **`수창 감귤박 문의접수`** 로 바꿉니다

> 시트 탭(문의접수)은 첫 문의가 들어올 때 **자동으로 만들어지니** 직접 만들 필요 없습니다.

---

## 2단계 — 코드 붙여넣기

1. 시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script** 클릭 (새 탭이 열립니다)
2. 화면 가운데 이미 적혀 있는 코드(`function myFunction() { }`)를 **전부 지웁니다**
   - 코드 아무 곳이나 클릭 → `Ctrl + A` (전체 선택) → `Delete`
3. 이 폴더의 **`apps-script\Code.gs`** 파일을 메모장으로 열어 **전체 복사**(`Ctrl+A` → `Ctrl+C`)
4. Apps Script 화면에 **붙여넣기**(`Ctrl+V`)
5. 위쪽 **저장 아이콘(💾)** 클릭 — 또는 `Ctrl+S`

---

## 3단계 — 권한 승인 (여기서 겁나는 화면이 나옵니다)

> ⚠️ **"실행 버튼이 안 보여요" — 가장 많이 막히는 곳입니다.**
> - **저장(`Ctrl+S`)을 먼저 해야** 실행 버튼과 함수 목록이 나타납니다. 저장 안 하면 안 보입니다.
> - 저장하면 화면 **위쪽 가운데**에 이 줄이 생깁니다:
>   `▷ 실행` | `🐞 디버그` | `[함수 선택 ▼]` | `실행 로그`
>   (오른쪽 위 파란 **배포** 버튼과는 다른 것입니다)
> - 🟢 **그래도 안 보이면 이 3단계는 건너뛰고 바로 4단계로 가세요.**
>   똑같은 권한 승인 화면이 **배포할 때도 나옵니다.** 3단계는 미리 시험해보는 단계일 뿐 필수가 아닙니다.

1. 화면 위쪽 **[함수 선택 ▼]** 칸에서 **`테스트_문의보내기`** 를 고릅니다
2. **▷ 실행** 버튼 클릭
3. **"승인 필요"** 창이 뜨면 → **권한 검토** 클릭
4. 계정 선택 → **`suchang.marketing@gmail.com`** 클릭
5. ⚠️ **"Google에서 확인하지 않은 앱"** 이라는 경고가 나옵니다. **정상입니다.**
   내가 직접 만든 스크립트라 구글이 아직 검토하지 않았다는 뜻일 뿐입니다.
   - 왼쪽 아래 **고급** 클릭
   - 맨 아래 **`제목 없는 프로젝트`(으)로 이동(안전하지 않음)** 클릭
6. **허용** 클릭

### 확인
- `suchang.marketing@gmail.com` 받은편지함에 메일 **2통**이 왔으면 성공입니다
  - `[문의] 테스트상사 · 가축 사료` (담당자 알림)
  - `[(주)수창] 문의가 정상 접수되었습니다` (자동회신)
- 구글 시트로 돌아가 보면 **문의접수** 탭이 생기고 테스트 한 줄이 저장돼 있습니다

> 메일이 안 왔다면 **스팸함**을 먼저 확인하세요.

---

## 4단계 — 웹에 연결하기 (배포)

> 3단계를 건너뛰셨다면, 이 배포 과정 중간에 **"액세스 승인"** 창이 뜹니다.
> → 계정 선택(`suchang.marketing@gmail.com`) → **"확인되지 않은 앱"** 경고에서
> **고급** → **`제목 없는 프로젝트`(으)로 이동(안전하지 않음)** → **허용**
> 순서로 진행하시면 됩니다. **정상적인 화면이니 놀라지 않으셔도 됩니다.**

1. Apps Script 화면 **오른쪽 위 파란 [배포] 버튼 → 새 배포** 클릭
2. 왼쪽 **톱니바퀴(⚙️) → 웹 앱** 선택
3. 아래처럼 설정합니다 — **이 두 줄이 제일 중요합니다**

   | 항목 | 설정값 |
   |---|---|
   | 설명 | 수창 문의폼 (아무거나) |
   | **다음 사용자로 실행** | **나 (suchang.marketing@gmail.com)** |
   | **액세스 권한이 있는 사용자** | **모든 사용자** ← ⚠️ 꼭 이걸로 |

4. **배포** 클릭
5. 나온 **웹 앱 URL**을 복사합니다
   - `https://script.google.com/macros/s/AKfy...../exec` 처럼 생겼고 **`/exec`로 끝납니다**

## 5단계 — 랜딩페이지에 주소 넣기

1. `index.html` 을 메모장으로 열고 `Ctrl+F` 로 **`GAS_URL`** 을 찾습니다
2. 이 줄을 찾아서

   ```js
   const GAS_URL  = '';
   ```

   따옴표 안에 복사한 주소를 붙여넣습니다

   ```js
   const GAS_URL  = 'https://script.google.com/macros/s/AKfy...../exec';
   ```

3. 저장 (`Ctrl+S`)

> 클로드에게 **"복사한 주소 넣어줘"** 하고 주소를 붙여주셔도 됩니다.

## 6단계 — 진짜로 되는지 확인

1. `index.html` 을 더블클릭해서 열고, 맨 아래 문의 폼을 **실제로 채워서** 보내보세요
   - 이메일 칸에는 **본인 이메일**을 넣으세요 (자동회신이 오는지 봐야 하니까요)
   - 전화번호는 비워 두셔도 됩니다 (선택 항목)
2. 확인할 것 세 가지
   - [ ] 화면에 **"문의가 정상 접수되었습니다"** 초록 상자가 뜨는가
   - [ ] 구글 시트에 한 줄 쌓였는가
   - [ ] 메일 2통(알림·자동회신)이 왔는가

## 알아두실 것

**메일 발송 한도** — 무료 지메일 계정은 **하루 100통**까지 보낼 수 있습니다.
문의 1건당 2통(알림+자동회신)이 나가므로 **하루 50건**까지는 문제없습니다.

**코드를 고친 뒤에는 다시 배포해야 반영됩니다**
→ `배포 → 배포 관리 → 연필(✏️) → 버전: 새 버전 → 배포`
(이때 웹앱 주소는 그대로라 `index.html`은 안 고쳐도 됩니다)

**자주 바꾸실 만한 것** — `Code.gs` 맨 위 설정 부분만 고치면 됩니다
- `ADMIN_EMAIL` : 알림 받을 주소
- `REPLY_HOURS` : 자동회신에 적히는 회신 소요 시간 (지금은 "영업일 기준 1~2일")
- 자동회신 문구 : `sendAutoReply` 함수 안의 글

**개인정보** — 폼에 수집·이용 동의 체크박스를 넣어 두었습니다.
시트에 개인정보가 쌓이므로, 이 구글 시트는 **아무에게나 공유하지 마세요.**

## 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| "접수 중 문제가 생겼습니다" | 4단계에서 **액세스 권한**이 "모든 사용자"가 아닐 가능성이 큽니다. 배포 관리에서 다시 확인 |
| 시트에는 쌓이는데 메일이 안 옴 | 스팸함 확인 → 그래도 없으면 하루 100통 한도 초과인지 확인 |
| 자동회신만 안 감 | 하루 100통 한도를 넘었거나 신청자 주소에 오타가 있는 경우입니다. 시트의 "자동회신" 칸에 `실패`로 기록됩니다 |
| 시트 칸이 밀려서 저장됨 | 예전 버전으로 만든 **문의접수** 탭이 남아 있는 경우입니다. 그 탭을 삭제하면 새 양식(10칸)으로 다시 만들어집니다 |
| 코드를 고쳤는데 그대로임 | **재배포**를 안 한 것입니다 → `배포 → 배포 관리 → 연필(✏️) → 버전: 새 버전 → 배포` |
