# 🔑 날씨 비서 챗봇 — API 키 설치 안내

> 챗봇은 **구글 제미나이(Gemini)** 를 씁니다. 무료 등급으로 쓸 예정이라 **결제수단은 등록하지 않습니다.**
> 키는 **서버에만** 저장되고 브라우저(사람들 화면)로는 절대 내려가지 않습니다.

---

## ① 무료 키 발급받기 (3분)

1. https://aistudio.google.com/apikey 접속 → 구글 계정으로 로그인
2. **[Create API key / API 키 만들기]** 클릭
3. 프로젝트를 고르라고 하면 아무거나(또는 새로 만들기) 선택
4. 만들어진 키를 **복사 버튼으로 복사** (길쭉한 영문·숫자 조합)
   - 시작 글자는 `AIza`일 수도, 다른 글자일 수도 있습니다. **뭐로 시작하든 상관없어요.**

> ⚠️ **결제(Billing) 설정은 하지 마세요.** 결제수단이 없으면 무료 한도를 넘겨도 요금이 나갈 길이 없습니다.
> ⚠️ **이 키를 채팅창·카톡·깃허브에 붙여넣지 마세요.** 아래 ② 방법으로만 넣습니다.

---

## ② 내 컴퓨터에서 쓰기 (로컬)

1. 파일 탐색기로 `D:\CLAUDE\jeju_vibe\weatherApp` 폴더 열기
2. `.env.local` 파일을 **마우스 오른쪽 → 연결 프로그램 → 메모장**으로 열기
   - 파일이 안 보이면: 탐색기 위쪽 **[보기] → [표시] → [숨긴 항목]** 체크
3. 아래 줄을 찾아서 `=` 뒤에 복사한 키를 붙여넣기 (따옴표·공백 없이)

   ```
   GEMINI_API_KEY=여기에붙여넣기
   ```

4. **저장(Ctrl+S)** 후 메모장 닫기
5. 실행 중인 서버를 껐다 켜기 — 터미널에서 `Ctrl + C` → `npm run dev`
6. 브라우저에서 http://localhost:3000 → 오른쪽 아래 **말풍선 버튼** 클릭 → "오늘 뭐 입을까?" 눌러보기

---

## ③ 인터넷에 배포된 사이트에서 쓰기 (Vercel)

1. https://vercel.com 접속 → 로그인 → **weather-app** 프로젝트 클릭
2. 위쪽 **Settings** → 왼쪽 **Environment Variables**
3. 아래처럼 입력하고 **Save**
   - Key(이름): `GEMINI_API_KEY`
   - Value(값): 복사한 키
   - Environments: **Production / Preview / Development 모두 체크**
4. 터미널에서 다시 배포

   ```bash
   cd D:\CLAUDE\jeju_vibe\weatherApp
   vercel deploy --prod
   ```

## 안전장치 (이미 코드에 들어 있음)

| 장치 | 내용 |
|---|---|
| 키 보호 | 키는 서버 코드(`app/api/chat/route.ts`)에서만 읽음. 브라우저 코드에 없음 |
| 깃 보호 | `.env*` 는 깃이 무시하도록 설정됨 → 실수로 깃허브에 올라가지 않음 |
| 사용량 제한 | 한 사람 하루 **30번**, 사이트 전체 하루 **300번**까지만 |
| 질문 길이 제한 | 500자까지 |
| 한도 초과 시 | 요금이 나가는 게 아니라 "내일 다시 시도해 주세요" 메시지가 뜸 |

## 비용 참고 (2026-08 기준)

- 사용 모델: **Gemini 3.5 Flash-Lite** (가장 빠르고 저렴한 등급)
- 무료 등급: Flash 계열은 무료 토큰 제공 (하루 사용량 제한 있음, 무료 등급은 대화 내용이 구글 제품 개선에 쓰일 수 있음)
- 혹시 유료로 전환하더라도: 입력 100만 토큰 $0.30 / 출력 100만 토큰 $2.50 수준
  → 대화 1번에 약 1원 미만. 요금보다 **키 유출**을 조심하는 게 핵심입니다.

## 문제가 생기면

| 증상 | 원인·해결 |
|---|---|
| "아직 챗봇 열쇠(API 키)가 설정되지 않았어요" | 키를 안 넣었거나, 넣고 서버를 재시작하지 않음 |
| "챗봇 열쇠에 문제가 있어요" | 키를 잘못 복사(앞뒤 공백·따옴표 포함) → 다시 붙여넣기 |
| "오늘은 여기까지예요" | 하루 사용 제한(30번)에 걸림. 내일 다시 |
| "무료 사용량을 다 썼어요" | 구글 무료 한도 초과. 잠시 후 또는 내일 다시 |
